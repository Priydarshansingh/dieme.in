# UI Skills: Master Design & Human Interface Engineering Protocol

This skill bundles and coordinates the three foundational UI skills:

1. **Art Direction & Anti-Slop (`taste-skill`)**
   - High information density, quiet hairline borders, purposeful interaction states.
   - Clean, thumb-friendly mobile layouts with zero overlapping elements or cut-offs.
   - Elimination of generic centered AI hero banners and monotonous pill tag grids.

2. **Design Tokens & Systems (`awesome-design-md`)**
   - True dark/light canvas tokens, specular subtle borders (`border-border/70`, `shadow-xs`).
   - Tabular numerics (`tabular-nums`) for currency, quantities, and balances.
   - Disciplined typographic scales and compact spacing.

3. **Natural Human Copy (`humanizer`)**
   - Direct, authentic industrial ERP terminology (e.g., Tally/Busy parity).
   - Zero robotic AI contrasts ("Not just X, but Y"), forced triads, or marketing fluff.
   - Crisp, functional micro-copy and labels.

## When to Apply
- Any time mobile or web screens are designed, restyled, audited, or refactored.
- Mobile views must ensure touch targets ≥ 36px, no horizontal gesture collisions, and compact grouped forms.
