# Dg-Images — Local AI Companion for Dieme Studio 🖼️⚡

On-device AI thumbnail inpainting and generative prompt daemon designed for the **Dieme** ecosystem.

## Features
- **ChatGPT Web Integration:** Embedded authenticated session runner for automated image prompting.
- **IPC Daemon:** Listens on port 5488 for thumbnail generation requests from Dieme Android app.
- **Direct Canvas Export:** High-resolution 1080p thumbnail export directly to gallery.
